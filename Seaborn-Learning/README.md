# Seaborn Learning and Data Visualization 📊

## Overview
This folder documents my learning journey with **Seaborn**, a Python library for statistical data visualization. I am practicing different plot types and applying them to data analysis projects.

## Learning Objectives
- Understand Seaborn and its relationship with Matplotlib.
- Create statistical plots using Python.
- Visualize distributions, relationships, and categorical data.
- Customize charts for clearer presentation.
- Apply visualization techniques to student performance data.

## How to Run
Install the required libraries:

```bash
python -m pip install seaborn pandas matplotlib
```

Run a script from the terminal:

```bash
python 01_seaborn_basics.py
```

Replace the filename with any other script you want to run.
