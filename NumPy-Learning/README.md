# NumPy Data Analysis Project

## Overview

This project demonstrates the use of NumPy for basic student marks data analysis.

The project analyzes the marks of 20 students and calculates important statistical values and performance information.

## Features

- Calculate the total number of students
- Calculate average marks
- Find highest and lowest marks
- Calculate median
- Calculate standard deviation
- Count passed and failed students
- Find students scoring 80 or above
- Sort student marks

## Technologies Used

- Python
- NumPy

## NumPy Concepts Used

- NumPy arrays
- `np.mean()`
- `np.max()`
- `np.min()`
- `np.median()`
- `np.std()`
- Boolean filtering
- Array sorting
- Array counting

## How to Run

Make sure Python and NumPy are installed.

Run the program using:

```bash
python 20_numpy_data_analysis_project.py
